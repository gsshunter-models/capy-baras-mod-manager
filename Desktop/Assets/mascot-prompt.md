# Capybara mascot

Created with the built-in `image_gen` tool. The generated PNG is saved here as `capybara-orange.png`, embedded in the app, and used to encode the multi-resolution Windows `app.ico` with `tools/make_capy_icon.py`. The original generated transparency is preserved.

Final generation prompt:

> Use case: logo-brand. Asset type: transparent mascot illustration for the Windows desktop app Capy Bara's Mod Manager, used both as a sidebar mascot and a small app icon. Create one charming, relaxed capybara sitting like a rounded loaf, three-quarter view facing left, unmistakable long blunt capybara muzzle, tiny rounded ears, warm caramel-brown fur, calm dark eyes and a small content smile. A bright whole mandarin orange with a single deep-green leaf rests on its head; one small orange sits beside its front paw. Polished clean sticker illustration, smooth confident dark-brown outlines, a few soft warm shadows, simple bold silhouette that reads well at small sizes. Center the complete animal and fruit with comfortable transparent padding. Warm brown, vivid orange and leafy green palette suited to a warm dark desktop interface. Genuinely transparent background. No words, letters, typography, watermark, frame, badge, scenery, or UI mockup.
