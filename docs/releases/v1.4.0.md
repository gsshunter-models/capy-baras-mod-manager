# Capy Bara's Mod Manager v1.4.0

Select an installed track to see an automatic, low-detail 3D preview of its terrain and available textures.

- Background loading, cancellation when you switch tracks, and an eight-scene cache.
- Drag to rotate, scroll to zoom, reset the view, or expand the viewer.
- Resolution slider: Low (65 x 65 mesh / 256px texture), Medium (129 x 129 / 512px, default), High (257 x 257 / 1024px), Ultra (512 x 512 / 2048px).
- A layout dropdown for track packs with multiple layouts.
- Reads loose track files and SAF entries without extracting entire archives.
- Play track now retains the player's saved setup, appearance, controls and graphics. It backs up the config, updates only the selected track and launches normally. Choose **New Race → Start** in MX Simulator. It no longer uses the single-AI `--track` startup mode.

The preview renders terrain and available ground decals, with approximate base tile colors. Objects, vegetation, buildings, skyboxes, normal maps and live erode are not rendered. Missing/protected resources can reduce detail or prevent a preview; protected content is not decrypted.

Download **CapyBaraModManager-v1.4.0-windows-portable.zip** below, extract the complete ZIP, and run **CapyBaraModManager.exe**. Windows, .NET 9 Desktop Runtime and Microsoft Edge WebView2 Runtime are required. All accompanying files must stay with the app. **SHA256SUMS.txt** contains the download checksum.

Existing manager data stays in the same local data folder. You can keep the previous portable version alongside this one. No changes to mx.exe, OpenGL DLLs, or camera/ReShade add-ons.

Validation: 26/26 core regression groups passed, including exact setup preservation and backups. Windows checks passed for height precision, mesh orientation, texture baking, all four resolutions, automatic selection, cancellation and cached reselection. Installed loose and SAF tracks were checked read-only; representative Medium previews completed in approximately 0.4–1.2 seconds on the development machine. Load times vary by track and computer.
