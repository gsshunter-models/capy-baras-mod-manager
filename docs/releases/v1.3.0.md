# Capy Bara's Mod Manager v1.3.0

Download **CapyBaraModManager-v1.3.0-windows-portable.zip** from the Assets section below. Extract the entire ZIP, open its folder, and run **CapyBaraModManager.exe**. Keep the DLLs, `runtimes` and `licenses` folders alongside the app.

Requires Windows, the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/9.0), and [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). The .NET runtime is not bundled. GitHub's separate **Source code** downloads contain the project for developers, rather than the ready-to-run app.

This release includes:

- Capybara mascots, oranges, a warm theme and the new app icon.
- Track, gear, helmet, bike and wheel inventory, sorting and groups.
- ZIP, SAF, RAR and 7z installs with preview, backups and undo.
- Track folders kept intact, including folders containing track SAF packages.
- Editable setup profiles and appearance presets.
- Forum browsing and direct public MediaFire, MEGA, Dropbox and archive downloads.
- Launching an installed track through MX Simulator's native launch option.

Existing settings and history remain under `%LOCALAPPDATA%\MXSimModManager`. The manager does not patch MX Simulator's executable or replace its OpenGL DLLs. New game content may require a normal game restart.

The source test suite passed all 25 test groups. `SHA256SUMS.txt` is attached for verifying the app download.
