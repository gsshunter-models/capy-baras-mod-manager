# Capy Bara's Mod Manager v1.4.5

Folders and packages above 40 GB can now be installed. This release removes the fixed 40 GB caps throughout installation and downloading.

- Removed the total-size cap for extracted mod folders and ZIP, RAR and 7z packages.
- Removed the individual-file cap for SAF installs and archive entries.
- Removed size caps from direct HTTP/MEGA downloads and downloads handled by the embedded browser, including transfers with an initially unknown size.
- Retained streamed copying, 64-bit byte counts, archive and download length verification, cancellation, partial-download cleanup, safe paths, backups and undo.

There is no app-imposed byte-size limit. Available disk space and filesystem limits still apply. Staging a package and backing up replaced files require extra free space. Existing file-count and folder-depth checks remain in place.

Validation: all 27 core test suites and the Windows terrain/UI checks pass. Regression tests exercise synthetic archive streams up to 64 GB without writing that data to disk, accept download metadata above 40 GB through the full 64-bit size range, and continue rejecting incomplete or overlong transfers. The release workflow tests and builds this source before publishing the portable app.

Download **CapyBaraModManager-v1.4.5-windows-portable.zip**, extract the entire ZIP, then run **CapyBaraModManager.exe**. Keep the accompanying files and folders together. Requires the .NET 9 Desktop Runtime and Microsoft Edge WebView2 Runtime.

Settings, groups, downloads, backups and undo history continue using `%LOCALAPPDATA%\MXSimModManager`.
